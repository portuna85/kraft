## 목적

[와우 인벤](https://wow.inven.co.kr/)의 커뮤니티 탐색 구조와 게시판 중심 정보 배치를 참고하여, 현재 Kraft의 기능으로 구성할 수 있는 반응형 웹을 설계한다. 사용자가 게시글을 읽고, 글과 댓글을 작성하며, 계정을 관리하는 흐름을 우선한다.

현재 Spring MVC·Thymeleaf·Bootstrap·jQuery 구조를 기준으로 단계적으로 적용한다. 이 문서에서 **현재**는 기준 커밋의 구현을, **목표**는 앞으로 적용할 디자인과 동작을 뜻한다.

## 설계의 중심 결정

1. 첫 화면은 `전체 게시글` 목록으로 구성한다. 제목과 작성자, 최종 수정일을 빠르게 읽을 수 있게 한다.
2. 넓은 화면은 탐색·게시판·이용 안내의 세 영역, 중간 화면은 두 영역, 작은 화면은 메뉴와 단일 열 본문으로 전환한다.
3. 기존 인디고 강조색에 짙은 헤더와 밝은 본문을 조합한다. 색상과 치수는 Kraft를 위한 제안값이다.
4. 기존 `/posts/update/{id}` 경로에서 읽기를 기본 상태로 제공하고, 권한이 있는 사용자에게 편집 진입을 제공한다.
5. 검색, 게시판 분류, 인기글, 추천·조회 수, 목록 댓글 수 등 데이터가 없는 요소는 이번 화면에 표시하지 않는다.
6. 실제 권한을 화면에 반영하기 위한 서버의 화면 모델 보완과, 이메일 인증 정책 변경 같은 별도 기능 작업을 구분한다.

## 조사와 검증 범위

- 참고 사이트의 공개 페이지 텍스트·HTML과 연결된 공개 CSS를 확인했다.
- 자동 승인 검토가 브라우저 화면 캡처 실행을 `blocked by policy`로 거절했다. 렌더링된 데스크톱·모바일 화면을 직접 검증하지 못했으며 스크린샷은 첨부하지 않았다.
- 현재 Kraft는 소스와 기존 테스트 코드를 기준으로 조사했다. 실행 화면 검증은 이번 문서 작업에 포함되지 않았다.
- 따라서 원본의 정확한 픽셀 배치·모바일 동작·이미지 크기를 재현했다는 의미가 아니다. 구현 전후 시각 검증 항목은 [구현 계획](04-implementation-plan.md)에 남겼다.
- 애플리케이션 코드와 데이터베이스는 이 문서 작업에서 변경하지 않았다.

첫 구현 단위는 공통 헤더·탐색과 게시글 목록이다. 상세·편집 화면은 권한 표시용 데이터가 준비된 다음 적용한다.
